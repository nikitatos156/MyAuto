# Сторонние компоненты

Код My Auto распространяется по [лицензии MIT](LICENSE). В приложение входят сторонние библиотеки и данные со своими лицензиями — тексты лицензий лежат рядом с файлами.

| Компонент | Для чего | Лицензия | Где |
| --- | --- | --- | --- |
| [React](https://react.dev) | интерфейс | MIT | npm |
| [react-icons](https://react-icons.github.io/react-icons/) / [Lucide](https://lucide.dev) | иконки | MIT / ISC | npm |
| [Capacitor](https://capacitorjs.com) | Android-приложение | MIT | npm |
| [Capgo Capacitor Updater](https://github.com/Cap-go/capacitor-updater) | обновления по воздуху | MPL-2.0 | npm |
| [Tesseract](https://github.com/tesseract-ocr/tesseract) / [tesseract.js-core](https://github.com/naptha/tesseract.js-core) | распознавание текста на устройстве | Apache-2.0 | `public/ocr/tesseract-core.LICENSE` |
| [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) (rus, eng) | языковые модели для распознавания | Apache-2.0 | `public/ocr/tessdata.LICENSE` |
| [PDF.js](https://mozilla.github.io/pdf.js/) | чтение PDF | Apache-2.0 | `public/pdfjs/LICENSE` |
| [jsPDF](https://github.com/parallax/jsPDF) | выгрузка в PDF | MIT | `src/vendor/jspdf.LICENSE` |
| [jsQR](https://github.com/cozmo/jsQR) | QR-код кассового чека | Apache-2.0 | заголовок `src/vendor/jsqr.umd.cjs` |
| [DejaVu Fonts](https://dejavu-fonts.github.io) | кириллица в PDF | Bitstream Vera / свободная | `src/vendor/fonts/DejaVu.LICENSE` |
| [esbuild](https://esbuild.github.io) | сборка (в приложение не входит) | MIT | npm |
